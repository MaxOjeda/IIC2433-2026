# IIC2433 - Minería de Datos ⛏📊
## Descripción
El desarrollo de la tecnología ha hecho que la mayoría de los datos almacenados de forma física ahora se almacenen de forma digital. Esto ha permitido que mediante algoritmos computacionales podamos extraer información de estos datos, ya sea patrones, modelos de predicción o identificar anomalías. Minamos estos datos para obtener conocimiento. En este curso se espera enseñar todo el proceso para poder minar conjuntos de datos, también conocido como Descubrimiento de Conocimiento en Base de Datos (Knowledge Discovery in Databases o KDD).
